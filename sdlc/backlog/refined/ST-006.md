# ST-006: Download spending diagram

**As a** user of Finanzuhu  
**I want to** download the spending diagram as a PNG image  
**so that** I can include it in a monthly report.

## Business context

The Spending page shows spending as either a category summary or a monthly summary, for a selected date range. The download should capture the diagram currently displayed, preserving its selected summary mode and date range.

The filename is based on the selected mode and displayed date range, with a six-character random alphanumeric suffix to distinguish downloads. Use the selected mode (`categories` or `months`) as the filename’s category/mode component and the displayed start and end dates in `YYYY-MM-DD` format.

## Acceptance criteria

1. The Spending page provides a control to download the currently displayed spending diagram as a PNG image.
2. The downloaded image represents the displayed diagram in its current summary mode and date range. In category mode, it includes all categories shown in the page; in month mode, it includes the months shown in the page.
3. The download does not navigate away from the Spending page or change spending data, the selected mode, or the selected date range.
4. The filename identifies the selected mode and date range, uses the displayed start and end dates in `YYYY-MM-DD` format, and ends in a six-character suffix containing ASCII letters and digits before the `.png` extension.
5. The download control is disabled while the chart is unavailable, including during loading, after a load failure, for an invalid date range, or when the selected view has no data.

## Not part of this story

- Other export formats, including SVG or PDF
- A separate or reformatted report-ready diagram
- Downloading empty-state, loading, or error-state images
- Detecting files already present in the user’s Downloads folder or numbering downloads based on those files
- Changing spending data or adding category selection

## Dependencies

- The existing Spending page, chart, and spending data.
- Browser support for downloading a generated PNG image.

## Open questions

- None.
