# ST-005: Transaction CSV export

**Source:** [`unrefined/ST-005.md`](../../unrefined/done/ST-005.md)  
**Status:** refined

**As a** user of Finanzuhu  
**I want to** download all transaction data as a CSV file from the Transactions page  
**so that** I can use the data outside the application.

## Business context

The Transactions page is the place where users view ledger entries. This story
adds a download of the complete ledger from that page. It is not affected by
transaction-page filters: the export always includes all transactions.

The exported fields mirror the visible transaction-table columns: date,
description, category, method, and amount. Dates and amounts use the same
German-style formatting shown in that table.

## Acceptance criteria

1. The Transactions page provides a control to download the transaction data as
   a CSV file.
2. Activating the control downloads a CSV file without navigating away from the
   Transactions page.
3. The CSV contains every transaction in the ledger, regardless of any filters
   or search terms currently applied on the Transactions page.
4. Each exported transaction contains exactly these fields: date, description,
   category, method, and amount.
5. Date and amount values use the German-style formatting displayed in the
   transaction table.
6. The exported rows use the ledger's default data order.
7. Downloading a CSV does not create, modify, or remove transactions.

## Not part of this story

- Exporting only filtered, searched, or date-range-limited transactions
- Exporting the counterparty field or other transaction fields
- Choosing export columns or their order
- Other export formats, such as PDF, Excel, JSON, or an accounting-system
  integration
- Importing transaction data
- Changing transaction data

## Dependencies

- The existing Transactions page and transaction ledger data.
- Browser support for downloading generated files.
