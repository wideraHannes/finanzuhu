# ST-004: Historical spending overview

**Source:** [`unrefined/ST-004.md`](../unrefined/ST-004.md)  
**Status:** refined

**As a** user of Finanzuhu  
**I want to** view historical spending in a separate chart by category or by month  
**so that** I can compare how my expenses develop over time and across categories.

## Business context

The dashboard already contains a graph. This story adds a distinct historical
spending graph rather than changing or replacing that existing dashboard graph.
The new graph gives users two ways to summarize expense transactions: grouped
by spending category or grouped by month.

## Acceptance criteria

1. The application provides a new tab for the historical spending overview
   that is separate from the existing dashboard graph.
2. The historical spending overview displays a graph based on the available
   transaction data.
3. The tab provides exactly two selectable summary options: **Categories** and
   **Months**.
4. When **Categories** is selected, the graph summarizes spending grouped by
   transaction category.
5. When **Months** is selected, the graph summarizes spending grouped by
   transaction month.
6. The overview provides a date-picker control to select the start and end of
   the period included in the graph.
7. The graph only summarizes spending transactions whose dates fall within the
   selected period.
8. Changing between **Categories** and **Months** updates the displayed graph
   to the selected summary without navigating away from the overview.
9. The existing dashboard graph remains available and is not replaced by the
   historical spending graph.

## Not part of this story

- Changing the existing dashboard graph
- Adding further summary options beyond Categories and Months
- Budget planning, forecasting, or trend predictions
- Editing, importing, or exporting transaction data
- Adding or changing transaction categories

## Dependencies

- The existing transaction data and its category and date fields.
- The existing application navigation or tab component needed to expose the
  new overview.

## Open questions

- Where should the new tab be placed in the application: on the dashboard,
  on the transactions page, or elsewhere?
- Which of the two options should be selected when the overview first opens?
- What period should the overview show by default when it first opens?
- Which transaction types count as spending, especially for refunds or
  transfers?
- What should the graph show when no spending data exists for a month or
  category?
- Is a specific chart type or visual design required for either summary?
