# ST-001: Budget planner for categories

**Raised by:** Johannes Widera
**Status:** unrefined

## Idea

As a user I want to set a monthly budget per category so that I can see whether
I am still within my plan.

## Notes from the product side

- Budgets are set per category (the same categories the transactions already use)
- Monthly amounts — a budget is entered once and repeats every month
- Somewhere in the app there should be an overview: budget vs. actual spending
  for the current month, per category
- When a category is close to its budget or over it, that should be visible at a
  glance (colour, bar, something like that)
- Categories without a budget should not disappear from the view

## Open / unclear

- Where does the budget overview live — own page, dashboard widget, or inside the
  existing category view?
- Can budgets differ per month, or is one recurring amount enough for now?
- What happens to the budget of a category that is renamed or deleted?
- Is there a total budget across all categories, or only per category?
- Should income categories be budgetable at all?
- Where are budgets stored (`data/` like the rest, or user settings)?
- Notifications when a budget is exceeded — in scope or later?
