# ST-002: Multi language

**Raised by:** Gabriel
**Status:** unrefined

## Idea

As a user I want to use the app in my own language so that I do not have to work
with an interface in a language I am not comfortable with.

## Notes from the product side

- At least German and English to start with
- The user picks the language in the app; the choice is remembered
- All visible texts come from a translation file instead of being hard-coded
- Numbers, currency and dates should follow the selected language as well
- Adding a further language later should not mean touching every component again

## Open / unclear

- Which languages exactly for the first version — only DE/EN?
- What is the default: browser language, or a fixed fallback?
- Where does the language switch live (header, settings page)?
- Is the choice stored per browser or per user profile?
- Does existing data (category names, transaction descriptions from `data/`) get
  translated too, or only the UI chrome?
- Which i18n approach — Next.js built-in routing, or a library?
- Does the URL have to carry the language (`/de/...`)?
