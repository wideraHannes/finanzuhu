# 3. Implement a story

Implement @sdlc/backlog/refined/ST-XXX.md according to @sdlc/backlog/plans/ST-XXX_plan_v2.md.

## Before implementation

- Verify that the plan still matches the current codebase.
- Follow @sdlc/standards/architecture.md and preserve existing conventions.
- Implement the smallest complete solution that fulfils every acceptance criterion.

## Quality gates

- Add or update automated tests for the new behavior.
- Run relevant checks and the complete test suite.
- Investigate and fix failures caused by the change.

## Constraints

- Do **not** silently broaden scope or invent missing requirements.
- Stop and report a blocker when the story or plan requires a product decision.
- Keep the ticket, plan, tests, and code aligned.
- Do **not** create a review report in this step.

## Completion report

Report the implementation summary, changed files, test evidence, and any remaining risks or follow-up work.
