# 4A. Review an implementation

Review the current implementation of @sdlc/backlog/refined/ST-XXX.md against @sdlc/backlog/plans/ST-XXX_plan_v2.md.

## Mandatory review criteria

- Use @sdlc/standards/architecture.md and @sdlc/standards/definition_of_done.md.
- Inspect the implementation and its tests; do **not** rely only on the plan or prior reports.
- Verify acceptance criteria, correctness, regressions, error handling, input validation, security, maintainability, readability, architectural fit, test coverage, and documentation impact.
- Run relevant checks where possible.

## Review report

- List findings by severity.
- For each finding, include the affected file or area, evidence, impact, and a concrete recommendation.
- Record what was verified successfully and any checks that could not be run.

## Deliverable

Save the review as @sdlc/backlog/reviews/ST-XXX_review.md.
