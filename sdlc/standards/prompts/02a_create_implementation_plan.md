# 2A. Create an implementation plan

Create an implementation plan for @sdlc/backlog/refined/ST-XXX.md.

## Preparation

- Inspect the current implementation and relevant tests.
- Use @sdlc/standards/architecture.md to keep the design consistent with application boundaries and data flow.

## Plan contents

Write a precise, implementation-ready plan covering:

- affected files, components, APIs, domain logic, and tests;
- the change required in each place and why it is needed;
- intended data flow, validation, and error handling;
- test cases mapped to each acceptance criterion;
- risks, assumptions, and questions to resolve before implementation.

## Constraints

- Do **not** change application code.
- Do **not** invent requirements; call out ambiguities instead.

## Deliverable

Save the plan as @sdlc/backlog/plans/ST-XXX_plan.md.
