# 2B. Review an implementation plan

Review @sdlc/backlog/plans/ST-XXX_plan.md for @sdlc/backlog/refined/ST-XXX.md.

## Review criteria

- Validate the plan against the current codebase and @sdlc/standards/architecture.md.
- Confirm that every acceptance criterion is addressed.
- Check that affected files are complete, data flow is sound, and the test strategy can prove the intended behavior.

## Review output

- Summarize the plan's strengths and weaknesses.
- Identify missing work, incorrect assumptions, unnecessary complexity, architectural violations, risks, and unclear decisions.
- For every finding, explain the recommended change and why it matters.
- Write a complete revised plan, not a patch or a list of suggestions.

## Deliverable

Save the revised plan as @sdlc/backlog/plans/ST-XXX_plan_v2.md. Do **not** modify the original plan.
