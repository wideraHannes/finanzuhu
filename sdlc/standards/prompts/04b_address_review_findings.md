# 4B. Address review findings

Assess and address the findings in @sdlc/backlog/reviews/ST-XXX_review.md for @sdlc/backlog/refined/ST-XXX.md.

## Rework process

- Work through findings one at a time, prioritizing higher-severity issues.
- Validate each finding against the current code before changing it.
- Implement only justified fixes that stay within the story's scope and follow @sdlc/standards/architecture.md.
- Add or update tests for every behavior change.
- Run relevant checks and the full test suite after the rework.

## Constraints

Do **not** dismiss a finding without documenting evidence and a clear rationale.

## Deliverable

Update @sdlc/backlog/reviews/ST-XXX_review.md with the disposition of every finding: **fixed**, **not reproducible**, **accepted risk**, or **deferred**. Include the evidence for each disposition and the test results.
