# Architecture

**What is this?** The description of how this system is built. It is the
specification that planning, implementation and reviews are run against.

**Why is this especially important with AI?** An agent knows a thousand ways to
solve a problem, but not *the one* that fits this system. Without this file it
builds something plausible that does not belong in the project.

> This file is worked out together with the AI when setting up a run — ideally in
> session 2, right before the first implementation plan.
